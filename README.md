# Суррогатная модель напряженно-деформированного состояния термопласта, упрочненного однонаправленными углеродными волокнами
Объектом исследования является процесс прогнозирования механических свойств термопласта: полисульфона, армированного однонаправленными углеродными волокнами T700. Проблема заключается в том, что физические испытания являются ресурсоемкими, а компьютерное конечно-элементного моделирование требует большое количество времени и вычислительных мощностей. Актуальность работы обусловлена необходимостью ускорения цикла проектирования и сертификации композитных материалов в аэрокосмической отрасли и машиностроении, где требуется предварительная оценка прочностных характеристик без разрушения образцов.
Целью работы является создание суррогатной модели для предсказания полных диаграмм “напряжение–деформация” композитного образца. Для достижения поставленной цели был проведены структурный анализ предметной области и текущего процесса проектирования материалов композитов, сгенерирован обучающий датасет посредством алгоритмов пространственной упаковки волокон и компьютерного FEM-моделирования с помощью Abaqus, сформирована математическая модель оптимального алгоритма машинного обучения для предсказания кривых деформации-напряжения, разработана и обучена суррогатная модель на сгенерированном датасете, реализован программный интерфейс для взаимодействия между пользователем и моделью, проведена экспериментальная оценка суррогатной модели с использованием предложенных метрик для адаптирования модели под потребности производства.
В результате создана функционирующая суррогатная модель, обеспечивающая прогнозирование диаграмм “напряжение–деформация” для образца. По результатам экспериментальной оценки гибридная модель достигла коэффициента детерминации R²=0,9944 и средней абсолютной процентной ошибки MAPE=1,55%. Время работы модели составило приблизительно 1 секунду на образец, что обеспечило ускорение вычислений в 480 раз по сравнению с традиционным FEA моделированием в Abaqus и подтвердило достижение поставленной цели.
## Как запустить:
```
$ pip install -r requirements.txt
$ python server.py
```

## Файлы репозитория
* server.py - запускает клиент-серверное приложение на основе FastAPI и JS.
* generate.py - Abaqus скрипт для генерации данных. Запустив первый раз создает cae файл, inp файл для осуществления разрыва и воксельное представление в виде файлов csv в качестве входных данных для нейросети. Запускается через команду ```$ abaqus cae noGUI=generate.py```. Запустив виртуальный эксперимент разрыва можно через команду ```$ abaqus job=RVE_Job cpus={n}```, где n - количество процессоров. После виртуального эксперимента получаем файл с расширением odb, запустив скрипт в той же папки еще раз (```$ abaqus cae noGUI=generate.py```) он извлекает кривую напряжение-деформация из сделанной работы (файл odb). Можно запустить через интерфейс abaqus.
* CNN_GPR.ipynb - ноутбук для обучения основной нейросети предсказания кривых напряжение-деформация
* MLP.ipynb - в качестве примера был рассмотрен MLP вариант, не подходит для промышленного обучения
* rves, strain-stress - датасет, применяемый в качестве примера.
